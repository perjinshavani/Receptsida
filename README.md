# Receptsida

## Syfte

Syftet med projektet var att öva på att bygga en responsiv och tillgänglig webbplats med HTML och CSS. Projektet fokuserade på semantisk HTML, CSS Grid, Flexbox, BEM, CSS-variabler och en tydlig kodstruktur.

## Om projektet

Receptsida är en responsiv webbplats byggd med HTML och CSS. 

## Funktioner

- Responsiv design för mobil, surfplatta och dator
- Hero-sektion
- Receptkort i en responsiv grid-layout
- Tydlig navigation
- Semantisk HTML
- Tillgänglig webbdesign

## Tekniker

- HTML
- CSS
- CSS Grid
- Flexbox
- CSS-variabler
- BEM
- Git & GitHub

## Det här har jag lärt mig

Genom projektet har jag övat på att:

- Använda semantiska HTML-element som `header`, `main`, `nav`, `section` och `article`.
- Skapa en **Skip Link** (`Hoppa till innehåll`) med `id="main-content"` för bättre tillgänglighet.
- Testa webbplatsens tillgänglighet med **WAVE** och **Lighthouse**.
- Bygga en responsiv layout med **CSS Grid**, **Flexbox** och **media queries**.
- Använda `rem` istället för `px` för bättre skalbarhet.
- Använda en CSS Reset för en enhetlig grund.
- Skapa och återanvända CSS-variabler.
- Strukturera CSS med **BEM**.
- Organisera CSS-klasser för bättre läsbarhet och underhåll.
- Använda nästlad CSS för att strukturera stilar för bilder.
